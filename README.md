# Бот-магазин с админ-панелью

Telegram-бот (aiogram 3) и сайт-админка (Flask) работают в одном процессе и делят одну базу SQLite.

**Что умеет админ-панель**
- Рассылка всем пользователям бота (текст с форматированием + картинка)
- Баннеры: показываются в приветствии бота, можно скрывать и удалять
- Категории и товары (фото, описание, скрытие товара)
- Изменение цены у одного товара и массовое (на N процентов по категории или всем)
- Промокоды: процент или фиксированная сумма, лимит использований, срок действия
- Заказы со сменой статуса; о новом заказе бот пишет админам

**Как устроен вход.** Вы пишете боту `/admin`, он присылает одноразовую ссылку на сайт (живёт 10 минут, работает только для ID из `ADMIN_IDS`). Остальным пользователям бот на `/admin` не отвечает. Дальше вход помнится на 7 дней. Запасной вариант — пароль `ADMIN_PASSWORD`.

## Запуск

1. Создайте бота в @BotFather и возьмите токен. Свой Telegram ID узнайте у @userinfobot.
2. Скопируйте `.env.example` в `.env` и заполните `BOT_TOKEN`, `ADMIN_IDS`, `WEB_URL`.
   `.env` в GitHub не загружайте (он уже в `.gitignore`). На хостинге те же значения вводятся в разделе переменных окружения.
3. Проверка на своём компьютере:
   ```
   pip install -r requirements.txt
   python main.py
   ```
   Для проверки поставьте `WEB_URL=http://localhost:8080`, отправьте боту `/admin` и откройте ссылку.

## Хостинг для ботов

- Команда запуска: `python main.py`, зависимости берутся из `requirements.txt`.
- Задайте переменные окружения из `.env.example`.
- Сайт слушает порт из переменной `PORT`. Хостинг должен отдавать этот порт наружу по домену или адресу: этот адрес и есть `WEB_URL` (лучше с `https://`).
- Папка `data/` хранит базу и загруженные картинки. Она должна переживать перезапуски: подключите постоянный диск и укажите путь в `DATA_DIR`. Иначе при новой загрузке кода товары пропадут.
- Сайт и бот должны работать вместе на одном хостинге, потому что у них общая база.

## Если у вас уже есть свой бот

Панель работает с таблицами `users`, `categories`, `products`, `banners`, `promocodes`, `orders`, `broadcasts` (схема в `db.py`). Рассылки панель кладёт в таблицу `broadcasts`, а бот их отправляет (`broadcast_worker` в `bot.py`).

## Файлы

- `main.py` запускает бота и сайт
- `bot.py` бот: каталог, покупка с промокодом, `/admin`, отправка рассылок
- `web.py`, `templates/`, `static/` админ-панель
- `db.py` база данных, `config.py` настройки
